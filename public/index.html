Configuração e Tutorial do Google Drive (Evitar Erros de Autenticação)
Como evitar o erro "OAuth Client was not found"? Como este aplicativo é executado no seu celular ou no seu próprio domínio no GitHub Pages, você precisa registrar um identificador (Client ID) no Google Cloud Console para autorizar o salvamento de arquivos no seu Drive. Siga o passo a passo simples abaixo:
  1. Acesse o Google Cloud Console com sua conta Google.
  2. Crie um novo projeto com qualquer nome (ex: "Controle Horas").
  3. No menu lateral, vá em Tela de consentimento OAuth, escolha o tipo de usuário Externo (ou Interno), preencha o nome do app e seu e-mail, salve e clique em Publicar Aplicativo (ou adicione seu e-mail como Usuário de Teste).
  4. Vá em Credenciais -> clique em + Criar Credenciais no topo -> escolha ID do cliente OAuth.
  5. Selecione Tipo de Aplicativo: Aplicativo da Web.
  6. No campo Origens JavaScript autorizadas, adicione exatamente a URL de onde você abre o app (ex: https://andreturco.github.io).
  7. Clique em Criar, copie o ID do cliente gerado (um texto longo que termina em .apps.googleusercontent.com) e cole-o no campo de entrada abaixo.
Recomenda-se exportar sua planilha ou JSON semanalmente para salvaguarda.

Automação Wi-Fi com MacroDroid

O MacroDroid é um aplicativo gratuito de automação para Android que permite enviar chamadas HTTP em segundo plano no momento exato em que certas condições acontecem.

1
Instale o MacroDroid:

Baixe gratuitamente o aplicativo MacroDroid na Google Play Store.

2
Crie uma Nova Macro:

Abra o app, clique em "Adicionar Macro" e defina o nome como "Chegada em Casa".

3
Gatilho (Vermelho):

Clique em + nos Gatilhos -> selecione Conectividade -> Mudança de estado do Wifi -> escolha Conectado à rede -> e selecione o SSID do Wi-Fi da sua casa.

4
Ação (Azul):

Clique em + nas Ações -> selecione Aplicativo -> Abrir URL/Requisição HTTP -> configure como HTTP POST e preencha o campo de URL exatamente com:

http://192.168.2.123:3080/api/auto-arrival
5
Salve e Ative:

Toque no ícone de disquete para salvar a macro. Pronto! A chegada em casa baterá automaticamente assim que conectar no Wi-Fi.
